01 Problem

Every agent decision is a slow, expensive LLM call.

Most of an agent's model calls don't write anything. They decide. And each one goes to a giant text generator.

02 How it works

Decido reads the decision straight from the model. Nothing is generated.

LLM TODAYPrompt→Generate text→Parse it→Answer2–5 s · varies
DECIDOTyped question→Read probabilities→Answer~0.1 s · deterministic
# situation + typed questions in, probabilities out
from decido import Decido

d = Decido()
r = d.decide(ticket, {
  "refund":  "Is the customer asking for a refund?",
  "team":    {"type": "choice", "question": "Which team?",
              "options": ["billing", "technical", "sales"]},
  "urgency": {"type": "score", "question": "How urgent?",
              "levels": ["Low", "Medium", "High"]},
})

if r["refund"].answer == "yes" and r["refund"].p >= 0.95:
    issue_refund()       # confident: act
else:
    send_to_human()      # unsure: escalate
PYTHON SDK. Same JSON over a local HTTP API, an MCP server (Claude Code, Cursor) and LangChain / LangGraph tools.
Any question typeYes/no, pick one, or a score. Write the question in plain English.
A confidence score for every optionTemperature-calibrated on held-out tasks, so you can set a threshold: act when sure, ask a human when not.
The same answer every timeBit-for-bit repeatable on CPU. Replay any past decision for an audit.
Runs anywhereLaptop, server, private cloud or air-gapped. CPU or GPU. No per-call fees.
Two sizesDecido Full (26B mixture of experts, 4B active) for accuracy. Decido Fast (1.7B) for speed.

04 Where it fits

Anywhere an agent has to make a call.

Agent guardrails

Check every action before it runs. Block the dangerous ones, ask a human about the borderline ones.

"Is it safe to run this command?"

Routing and triage

Send each ticket, call or case to the right place, and only escalate when the model isn't sure.

"Which team should handle this?"

Voice and support agents

Decide mid-conversation, in a fraction of a second, without sending the conversation to a third party.

"Does the caller want a human?"

Decisions on private data

Refunds, claims, alerts and approvals, with a record of every decision that you can replay exactly.

"Is this refund within policy?"
