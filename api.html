Decido API

Free tier · Decido-1-Fast · last updated 7 November 2026

Send a document and typed questions, get a probability for every answer. The request and response use the same format as decido serve and the Jev 1.13 API, so the same code runs against this free hosted API, against your own server, or locally with pip install decido-ai.

Get a free API key

Endpoint

POST https://getdecido.ai/v1/systemone
Authorization: Bearer dk_…
Content-Type: application/json

GET https://getdecido.ai/v1/models lists the hosted models (no key needed).

Authentication

  • Send your key as Authorization: Bearer dk_… — the header the Jev / TypeSafe SDKs send.
  • Get a key on the playground after a quick human check: one key per network per day, no sign-up, no email. The key is shown once; we store only its SHA-256 hash, so a lost key cannot be recovered — create a new one the next day.
  • Revoked or unused keys are deleted 90 days after last use. Keys used for abuse may be revoked.
  • Call the API from your server only. There are no CORS headers on purpose: a key in browser code is public.

The free API takes plain-text instructions; structured (object) instructions return 422 — they work with decido serve.

curl -s https://getdecido.ai/v1/systemone \
  -H "Authorization: Bearer $DECIDO_API_KEY" -H "Content-Type: application/json" -d @- <<'EOF'
{
  "state": "Customer: I was charged twice for order 4821. Please refund one of the charges.",
  "questions": {
    "refund": {"type": "noul", "instructions": "Is the customer asking for a refund?"},
    "team": {"type": "choice", "instructions": "Which team should handle it?",
             "criteria": {"billing": "Charges, refunds, invoices", "shipping": "Deliveries", "tech": "Bugs and outages"}},
    "urgency": {"type": "score", "instructions": "How urgent is it?", "criteria": ["low", "normal", "urgent"]}
  }
}
EOF

Response

{
  "model": "decido-1-fast",
  "answers": {
    "refund":  {"type": "noul", "noul": 0.97},
    "team":    {"type": "choice", "choice": "billing", "probabilities": {"billing": 0.92, "shipping": 0.03, "tech": 0.05}, "confidence": 0.9},
    "urgency": {"type": "score", "score": 0.94, "legend": {"0": "low", "1": "normal", "2": "urgent"},
                "probabilities": {"0": 0.3, "1": 0.47, "2": 0.24}, "confidence": 0.2}
  },
  "usage": {"input_tokens": 212, "output_tokens": 0}
}

noul is P(yes). choice is the most likely option, with a probability for every option. score is the expected level (0 = first level), with a probability per level. Example values; yours will differ.

Limits (free tier)

per key50 requests per UTC day · 10 per minute · 1 at a time · 150 compute-seconds per day
per requestup to 5 questions · up to 10 options per question · up to 80 characters per option (name + description) · document up to 6,000 characters · about 2,500 characters of English in total (hard limit: 1,000 tokens for the document plus all questions; 3,000 bytes of text) · body up to 32 KB · no images
bodiesuncompressed, or Content-Encoding: gzip (a single gzip stream); at most 32 KB before and after decompression. zstd bodies aren't accepted yet (415)
shared capacitythe free API shares a daily capacity with the online demo; when it is used up you get 503 until 00:00 UTC

Successful responses, and 429 responses for the daily quota or the per-minute rate, carry X-RateLimit-Limit, X-RateLimit-Remaining (requests left today) and X-RateLimit-Reset (Unix time of the next reset). 429 and 503 responses carry Retry-After (seconds).

Errors

Errors are JSON: {"detail": "…"}.

statusmeaning
400body is not valid JSON, or a malformed gzip body
401missing or invalid API key
413too big: more than 5 questions or 10 options, an option over 80 characters, over the text or token limit (“API limit 1,000 tokens”), or a body over 32 KB (also after decompression)
415not application/json, an unsupported or doubled Content-Encoding (including zstd, for now), or multi-member gzip
422validation error: missing field, unknown question type, fewer than 2 options, non-string instructions, unknown model, images
429daily quota used up, more than 10 requests per minute, a second request while one is running, or too many invalid API keys (or rejected requests) from your network in a minute
502the model is unavailable (retry later)
503busy, today's free capacity is used up, or the free API is paused
504the model did not answer in time

Jev / TypeSafe SDK

Point the client at Decido and use your Decido key. Small requests work as they are; the SDK zstd-compresses larger bodies (about 1 KB and up), which the free API doesn't accept yet — for those, send plain JSON or gzip (see curl/Python above), or run decido serve locally. Model names such as jev-latest run on Decido-1-Fast.

export TYPESAFE_API_KEY="$DECIDO_API_KEY"

from typesafe_sdk import TypeSafeClient, Noul
with TypeSafeClient(base_url="https://getdecido.ai") as client:
    r = client.system_one(state="Customer: I was charged twice for order 4821.",
                          questions={"refund": Noul(instructions="Is the customer asking for a refund?")})
    print(r.answers["refund"].noul)

Privacy

Documents, questions and answers are processed in memory and not stored or used for training. Request metadata (time, status, size, key prefix, country) is kept for up to 30 days. For each key we keep its SHA-256 hash, a short display prefix, your label, the network (IP address or IPv6 /64) it was created from, and when it was created and last used, for the life of the key. Details: privacy, terms.

Production use

The free tier has no SLA and small limits. For production volume, bigger models or sensitive data, run Decido yourself — same request format, no limits, nothing leaves your machine:

pip install decido-ai
decido serve decido-ai/decido-1-26b-a4b --port 8080      # or decido-1-fast-1.7b, decido-1-max-26b-a4b, …
curl -s localhost:8080/v1/systemone -H 'content-type: application/json' -d @request.json
